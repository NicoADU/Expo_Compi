📖 Descripción

Este repositorio contiene el material, ejercicios, ejemplos y actividades desarrolladas durante el curso de Lenguajes y Compiladores.

El objetivo principal es comprender cómo funcionan los lenguajes de programación y las diferentes etapas que intervienen en la construcción y ejecución de un programa mediante un compilador.

🧪 Ejemplo

Uno de los ejemplos desarrollados en el curso muestra de manera simplificada cómo un compilador procesa una expresión:

int x = 10 + 20 * 2;

El proceso puede representarse como:

Código fuente
     ↓
Tokens
     ↓
Árbol sintáctico (AST)
     ↓
Análisis semántico
     ↓
Representación intermedia
     ↓
Optimización
     ↓
Código ejecutable
     ↓
Resultado: x = 50
